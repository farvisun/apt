Farvisun APT Repository

Install Lumen and Desktop Studio with apt. Add the repository once, and both apps update with your normal system updates.

Add the repository

TERMINAL
curl -fsSL https://farvisun.github.io/apt/setup.sh | sudo bash

Then install what you want:

TERMINAL
sudo apt install lumen-launcher desktop-studio

How it stays safe

  • Signed. Every package list is signed, and apt refuses anything that doesn't match. The key is used only for this repository.
  • Built from public releases. Packages come from each project's GitHub releases and are checked against their published checksums.
  • Scoped trust. The key is stored in /etc/apt/keyrings and trusted only for this repository, not for your whole system.

Remove

TERMINAL
curl -fsSL https://farvisun.github.io/apt/setup.sh | sudo bash -s -- --remove

This removes the repository and its key. Apps you installed stay installed; remove them with sudo apt remove lumen-launcher desktop-studio.
